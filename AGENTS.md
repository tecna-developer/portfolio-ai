# AGENTS.md

## Проект
Одностраничное портфолио (https://tolstoukhova.com/): один `index.html`, один `style.css`,
один небольшой inline-скрипт. Без фреймворков, сборки и зависимостей. Не добавляй их.

## Команды
- Сборки, линтера и тестов нет.
- Локальный просмотр: `npx serve` (или просто открыть `index.html`).

## Структура
- `index.html` — вся страница: шапка, интро, сетка плиток, контакты, скрипт копирования email.
- `style.css` — все стили, сгруппированы по секциям.
- `img/`, `assets/` — изображения; `favicon.*`, `og-image.png`, `logo.svg` — иконки и превью.
- `.htaccess` — Apache-правила для Bluehost (канонический хост, https, без листинга каталогов).
- `.github/workflows/deploy.yml` — FTP-деплой на Bluehost при пуше в `main`.

## Соглашения
- Классы в стиле BEM (`.brand__name`, `.tile`, `.copy-email__icon`).
- Размеры в `px`; цвета и шрифт только через CSS-переменные (`--bg`, `--text`, `--text-soft`,
  `--tile-border`, `--shadow`, `--font`), без хардкода цветов.
- Все иконки и картинки плиток — inline SVG с палитрой соседних плиток, не файлы.
- Подпись плитки берётся из `data-name` (`content: attr(data-name)`), не дублируй её в разметке.
- Каждая плитка: `href`, `data-name` и содержательный `aria-label` (что за проект, а не только имя).
- Доступность обязательна: подпись видна и на `:focus-visible`, анимации отключаются при
  `prefers-reduced-motion: reduce`.
- Новая плитка дальше десятой требует своей `nth-child`-задержки анимации.

## Важно
- При изменении `style.css` увеличь версию в ссылке (`style.css?v=N` → `N+1`) — так
  сбрасывается кеш.
- Пуш в `main` автоматически деплоит сайт (кроме изменений в `.github/**` и `README.md`).
  Не пушь в `main` без явной просьбы.
- Не коммить секреты; FTP-доступы лежат в GitHub Secrets.
- Правила `.htaccess` (порядок www → https, проверка `X-Forwarded-Proto`) не менять без причины:
  ошибка даёт бесконечный цикл редиректов.
- `img/anna.jpg` нигде не используется — не удаляй без запроса.
- `v1-dark/` в `.gitignore` и не входит в репозиторий.
