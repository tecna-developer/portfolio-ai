# Maksims redesign case

Adapted from Maksims/outputs/portfolio-case on 12 October 2026. Source materials remain unchanged.

The homepage embeds this independent eight-slide bilingual English/Russian case under Website redesigns. It is not a commissioned client project, and no conversion improvement is claimed.

Integration retains the supplied colours, typography, screenshots and narrative. Mobile controls appear above the slides; the frame follows the active slide height. Arrow keys, Home/End, dots and native horizontal scrolling are supported. Inactive slides are excluded from keyboard focus. The full page links back to the portfolio.

English is the default embedded version (en.html); Russian remains in index.html. EN / RU links preserve the current slide and embedded mode. Slide 7 shows a real mobile screenshot of the published concept captured at a 390 px viewport on 12 October 2026. The image opens at full resolution.

QA: Chromium at 320, 390, 768, 1024 and 1440 px; all eight slides checked for missing images, content/footer overlap, page overflow and iframe height. Keyboard navigation checked. Desktop and mobile screenshots visually inspected. No publication performed.
